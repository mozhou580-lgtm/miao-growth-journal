# 喵成长 · 小猫成长记录本

中文、单人单猫、手机优先的 PWA。记录保存在当前设备 IndexedDB；静态站点没有猫咪数据接口。

**共享版开发分支：**增加两人私密档案、验证码登录、专属邀请、逐条云同步、离线补传与冲突处理。正式云项目和验证码服务尚未开通，现有公开网址仍为本机版。接入步骤及验收边界见 [共享版接入说明](docs/shared-setup.md)。

公开正式入口：[打开喵成长](https://mozhou580-lgtm.github.io/miao-growth-journal/)。无需登录，支持添加到手机主屏幕。

## 手机使用与迁移

用手机浏览器打开部署网址，先添加到主屏幕，再从桌面打开并建立猫咪档案。iPhone 使用 Safari 的分享菜单；Android 使用浏览器的安装应用或添加到主屏幕选项。

换网址会使用新的浏览器存储。如已在[旧版入口](https://miao-growth-journal.mozhou580.chatgpt.site/)记录，请先在旧版的“设置与备份”中导出完整备份，再在新网址导入。建议从手机桌面打开新版后导入，并核对记录、花费和照片；网址之间没有自动迁移。

网站只有静态页面；自己的记录与照片不会提交到 GitHub。备份也保存在本机，请自行存到文件或云盘。

## 已实现

- 档案：姓名、头像、生日或估计生日、年龄。
- 成长：真实体重测量点、最近 12 次趋势、可筛选时间线。
- 饮食：食物、投喂克数、食欲观察；自动预填上一次食物与克数。
- 健康：疫苗、驱虫、就诊、用药、症状、体检；照片及 PDF 报告。
- 行为观察：玩耍、互动、躲藏、叫声、抓挠、环境变化及背景。
- 日常：文字与照片，记录可编辑、移除、撤销。
- 花费：按付款日期汇总人民币实付金额，分类、月预算、健康事件关联。
- 待办：自行填写照护日期、标记完成、导出 ICS 日历事件。
- 完整备份：JSON 包含照片与 PDF；预览、校验、合并去重、保留删除状态。
- 离线：首次联网完成资源缓存后，可打开、写入、刷新。

首页是明确标注的示例。建立真实档案从空白开始，不保存示例。

## 本地运行

需要 Node.js 20.19+ 或 22.12+，使用 pnpm 11.25.0，依赖版本由锁文件固定。

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm build
pnpm preview --host 127.0.0.1 --port 4173
```

生产构建执行 Vite 与 `scripts/build-sw.mjs`。开发模式不注册 service worker，离线检查请使用生产预览。网站需 HTTPS，localhost 可例外。

## 自动发布

已启用 GitHub Pages 与仓库变量 `DEPLOY_PAGES=true`，发布源为 GitHub Actions。每次推送 main 时执行测试、生产构建和资源校验，通过后自动发布。工作流会按照仓库名称设置网址子路径。

其他静态主机默认部署在 `/`。如需部署在子路径，构建前设置 `APP_BASE_PATH=/子路径/`，然后执行 `pnpm build` 和 `node scripts/check-build.mjs`。静态输出目录为 `dist`，所有安装资源与离线缓存都跟随同一个路径。

## 保存与边界

- 建议先添加到主屏幕，再从桌面打开并建档；持续使用同一个入口。换设备须先导出，再导入备份。
- 清理浏览器、系统回收存储或设备损坏可能造成丢失；每周手动备份。照片压缩至最长边 1400px。
- 每条记录最多 3 个附件，每个原文件不超过 5MB，支持 JPG、PNG、WebP、PDF。
- 当前是一只猫。另一只猫的备份不会覆盖已有档案。
- 日历导出是手动事件导出，通知需在手机日历中设置；网页没有后台推送。
- 观察记录不做医疗诊断或心理评分。
- 当前没有云同步、多人协作和 AI 自动录入。

## 源码结构

`model.js` 管理金额、日期、备份校验与合并；`storage.js` 负责 IndexedDB 和附件；`useJournal.js` 串行写入并等待事务完成；features 组织四个页面和表单；build-sw 生成带内容版本的资源缓存。

金额按整数分保存，消费月使用事件本地日期。删除留存 tombstone，旧备份无法复活较新的删除记录。导入不改变记录 ID。写入失败保留表单，不退回临时内存并声称成功。
